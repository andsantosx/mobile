# Assets

Esta pasta deve conter os ícones e splash screen do app.

Para gerar os assets automaticamente, você pode usar:
- icon.png (1024x1024)
- splash.png (tamanho recomendado)
- adaptive-icon.png (para Android)

Ou use o comando:
```bash
npx expo install expo-splash-screen
```

Por enquanto, o Expo usará assets padrão.
